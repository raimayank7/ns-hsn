SAC ᱠᱳᱰ ᱟᱨ ᱨᱮᱴ ᱱᱳᱴᱤᱯᱷᱤᱠᱮᱥᱚᱱ ᱢᱤᱫ ᱥᱟᱶ GST ᱨᱮᱴ ᱠᱚ ᱴᱷᱤᱠᱟᱣᱟ᱾ ᱟᱭᱢᱟ ᱥᱟᱨᱵᱷᱤᱥ 18% ᱨᱮ, ᱢᱮᱱᱠᱷᱟᱱ ᱛᱤᱝᱠᱟᱹᱢ ᱥᱚᱨᱛᱚ ᱥᱟᱶ 5% ᱨᱮ᱾ ᱴᱷᱤᱠ ᱮᱱᱴᱨᱤ ᱧᱮᱞ ᱢᱮ, ᱟᱨ ᱥᱚᱱᱫᱮᱦᱚ ᱠᱷᱟᱱ ᱮᱠᱟᱣᱩᱱᱴᱮᱱᱴ ᱠᱩᱞᱤ ᱮᱢ᱾
